Alpaca AI Trading Agents Hackathon · lablab.ai

Amanah Trader

Problem
Real mandates sometimes require refusing a profitable trade, and you have to prove an autonomous agent actually would.
Built
An options agent where the LLM can only pick from a deterministically ranked shortlist. Every order must clear six fail-closed gates (Shariah, structure, gharar, maysir, riba, risk) written in plain Python.
Result
Trades cash-secured puts on Alpaca paper, unattended, with 190 logged decisions, including the ones it refused.
  • Python
  • Alpaca API
  • LLM
  • Options
